# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer, for the make.fun bounty [Fortune Cookie Wisdom for Developers](https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44).

The program writes one line to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> You will meet a bug today that only exists when no one is watching.

Pure Python standard library, no network, deterministic output.
